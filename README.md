# SARVAX Enterprise Commercial Architecture & Pricing Proposal (v0.3.3)

> **“One enterprise contract. Multiple agents. Client-funded execution.”**

This repository contains the interactive executive commercial proposal, capability suite architecture, Workflow 2.0 DAG mapping, and 31-account evidence ledger for **SARVAX B2B AI Agents Platform** (C3A Labs).

---

## Executive Overview

SARVAX prices the **software operating layer and enterprise outcomes**. The client separately funds model inference, OCR, transcription, meeting bots, storage, and paid third-party data feeds directly with providers.

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. FIXED PLATFORM FEE (SARVAX AGREEMENT)                                 │
│    • Annual organization commitment                                     │
│    • Named advisor entitlements (accountability & governance)           │
│    • Activated capability suites (packaged outcomes, not bot SKUs)      │
│    • Workflow 2.0 orchestration & pre-built DAG templates               │
├─────────────────────────────────────────────────────────────────────────┤
│ 2. VARIABLE CONSUMPTION (CLIENT PAYS PROVIDERS DIRECTLY)                 │
│    • AI model tokens (DeepSeek, Gemini, Claude, Kimi K3) via BYOK        │
│    • Document OCR & text extraction                                     │
│    • Meeting recording & faster-whisper transcription                   │
│    • Paid data feeds (Morningstar, Reuters, Bloomberg)                  │
├─────────────────────────────────────────────────────────────────────────┤
│ 3. CUSTOM WORK (SEPARATE STATEMENT OF WORK)                             │
│    • Custom custodian integrations & bespoke agent development          │
│    • Billed under a separate, milestone-based SOW                        │
└─────────────────────────────────────────────────────────────────────────┘
```

## Key Commercial Features

1. **8 Detailed Client Value Journeys:**
   - **Aviva Naturals** (QA/QC & Lab Report Inbox Automation)
   - **NS Wealth** (~200 WhatsApp Groups to Tracker Automation)
   - **Arvocap Asset Managers** (10,000 Monthly Reports & IFA Support)
   - **Ladder7 Wealth Planners** (Digio KYC, Lead Capture & Rebalancing)
   - **BoxWealth Advisors** (M365 ↔ Zoho CRM Bidirectional Sync)
   - **FundsIndia** (WealthSpectrum & Morningstar RM Client 360)
   - **Hexagon Wealth** (Unified Wealth Systems Operating Layer)
   - **Entrust Family Office** (Consolidated Family Office Intelligence)

2. **All 12 Canonical Brochure Agents Mapped:**
   - Pre-Meeting Analysis Agent (`A01`)
   - Post-Meeting Analysis Agent (`A02`)
   - Client Intelligence Strategist (`A03`)
   - Portfolio Analysis Agent (`A04`)
   - Market Intelligence Agent (`A05`)
   - Document Intelligence Agent (`A06`)
   - KYC Intelligence Agent (`A07`)
   - Compliance Audit Agent (`A08`)
   - Campaign Intelligence Agent (`A09`)
   - Pipeline Monitoring Agent (`A10`)
   - Workflow Automation Agent (`A11`)
   - Advisor Performance Agent (`A12`)

3. **31-Account Evidence Ledger:**
   - Reconciles live Google Sheet tracker (`1ApSkZwwTdeUfaYvmsOWM5nVd6fBnXkz4EYm92orlGq4`), Drive exports, and Gmail/meeting evidence without inventing missing requirements.

4. **Sales Rules & Boundaries:**
   - Sell outcome suites, not 12 separate bot SKUs.
   - Client funds variable usage directly; credits are not platform price.
   - Catalog presence is not production-readiness proof.
   - Custom work requires a separate SOW.
